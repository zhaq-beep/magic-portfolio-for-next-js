## Pendahuluan ✨

Lembar ceklis ini dibuat dengan hati💖

Di project ini, saya mencoba membuat sebuah lembar ceklis sebagai kontrol amalan harian generus selama bulan ramadan. 
Diharapkan para Muballigh/ghot dan orang tua dapat bersama mengontrol para generus mulai dari,

- Memantau ibadah harian selama bulan Ramadan
- Melatih kedisiplinan
- Melatih karakter jujur
- Sebagai bahan muhasabah (introspeksi diri)
- Sebagai laporan ke guru/orangtua
- Motivasi konsistensi ibadah
- Menumbuhkan habit positif
- Menyukseskan 5 sukses Ramadan
